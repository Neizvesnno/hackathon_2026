# Картина під стіну

Застосунок підбирає картину під конкретну стіну: фотографуєш стіну або вибираєш її кольори —
і отримуєш 12 картин із датасету на 10 000 робіт, які пасують за кольором, жанром, століттям
і відомістю художника.

**Спробувати:** https://arts4us.streamlit.app (відкривається і з телефона)

Проєкт зроблено на хакатоні з Python на тему Open Data (KSE, 16 листопада 2026).

## Що вміє

- **Палітра стіни з фото.** 5 домінантних кольорів у просторі CIELAB (k-means) з частками площі.
- **Підбір за кольором.** Відстань між палітрами — CIEDE2000, зважена частками кольорів:
  велика пляма важить більше за дрібний акцент.
- **Два режими.** «Гармонія» шукає картини в кольорах стіни, «Акцент» — у комплементарних.
- **Прозорий рейтинг.** Оцінка складається з кольору, жанру, століття й відомості; ваги
  налаштовуються повзунками, а в картці видно внесок кожної складової.
- **«Відкриття ↔ відомі».** Повзунок піднімає маловідомих або знаменитих художників.
- **«Спершу українські автори».** Галочка, що виводить нагору картини українських художників.
- **Настрій.** Фільтр за настроєм картини (спокійний, драматичний, затишний…), розмітка — CLIP.
- **Приховати оголену натуру.** Перемикач за жанрами Wikidata і словами в назві (наближений).
- **Примірка.** Обрана картина накладається на фото кімнати з рамою і тінню.
- **Мапа мистецтва.** Усі 10 000 картин як точки в кольоровому просторі (t-SNE), підібрані підсвічено.

## Дані

10 000 картин XII–XXI століть, 5 783 художники. Метадані — з [Wikidata](https://www.wikidata.org) (CC0),
мініатюри — з [Wikimedia Commons](https://commons.wikimedia.org). Ліцензія й автор кожного файлу
вказані в `data/paintings.csv` і показуються під картиною в застосунку.

Вибірка стратифікована: не більше 15 картин на художника, 63% робіт — маловідомих авторів,
рівномірний добір за століттями й жанрами, 948 картин українських художників.
Докладно — `data/DATASET.md`.

## Як це влаштовано

```
data/                  датасет: CSV з метаданими і 10 000 мініатюр
pipeline/              extract_features.py — палітри й ознаки; mood_tags.py — настрої (CLIP)
app_data/              згенеровані файли: features.parquet, mood_tags.parquet, map_coords.parquet
core/                  palette.py (палітри), match.py (рейтинг), tryon.py (примірка), config.py
analysis/              art_map.py (мапа), defense_plots.py (графіки)
app/                   Streamlit-інтерфейс
CONTRACT.md            домовленості між модулями: схеми файлів і сигнатури функцій
```

Застосунок не читає 323 МБ картинок: він вантажить `features.parquet` (≈2,5 МБ) і показує
лише 12 мініатюр за посиланням. Підбір серед 10 000 картин займає близько 0,05 с.

## Запуск локально

```bash
git clone https://github.com/Neizvesnno/hackathon_2026.git
cd hackathon_2026
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app/main.py
```

Файли в `app_data/` уже лежать у репозиторії. Перебудувати їх можна так:

```bash
python -m pipeline.extract_features    # палітри й ознаки, кілька хвилин
python -m analysis.art_map             # координати мапи
python -m pipeline.mood_tags           # настрої; потрібні torch і модель CLIP, у requirements їх немає
```

## Обмеження

- Жанр, стиль і розміри є не в усіх картин — дані такі повні, як їх внесли у Wikidata.
- Відомість художника — наближення за кількістю мовних версій статті у Вікіпедії.
- Настрій і фільтр оголеної натури — автоматична розмітка, вона помиляється.
- Сучасних робіт мало: вони захищені авторським правом і рідко є на Commons.
